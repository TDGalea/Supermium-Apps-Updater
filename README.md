# Supermium Apps Updater
Supermium hasn't been able to create shortcuts on Vista since the dawn of time, so I finally took matters into my own hands.
Apparently this issue applies to XP too now, so there are two versions of the script. I'm sure they're named well enough to make it obvious which one you need.

Just download the appropriate script and run it. That's it.
If you have "installed" any websites, this script should find them and create the shortcuts in the Start Menu for you, under the "Supermium apps" folder - where they should've appeared in the first place.

Names should copy whatever you set when installing it, the icon will be whatever the tab icon was, and if the app was installed under a non-default Supermium profile, the profile will be named in the shortcut too.
